# ES6 Learning Path

[JavaScript Tutorial - ES6](https://www.javascripttutorial.net/es6/) site ကို reference အဖြစ် section တစ်ခုချင်း folder ခွဲပြီး လေ့လာမယ့် project ဖြစ်ပါတယ်။

## Prerequisites

ES5 JavaScript အခြေခံကောင်းကောင်းသိထားရပါမယ်။

## How to study

1. Section folder ထဲက `README.md` ဖတ်ပါ
2. Topic file တစ်ခုချင်းစီကို အစဉ်လိုက် လေ့လာပါ
3. Terminal မှာ example run ပြီး output ကြည့်ပါ

```bash
node es6/section-01-new-es6-syntax/01-let.js
```

4. `exercises/` folder ထဲက exercise တွေကို ကိုယ်တိုင်ရေးကြည့်ပါ
